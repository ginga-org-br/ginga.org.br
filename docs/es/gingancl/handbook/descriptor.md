# &lt;descriptor&gt;

El elemento [&lt;descriptor&gt;](descriptor.md) define los valores iniciales para las propiedades de
[&lt;media&gt;](media.md) elementos.  Estos valores iniciales se definen en atributos de
el elemento, o en elementos secundarios [&lt;descriptorParam&gt;](descriptorparam.md).

### Sintaxis { data-search-exclude }

| Elemento | Atributos | Contenido | Padre |
| --- | --- | --- | --- |
| [&lt;descriptor&gt;](descriptor.md) | <u>*id*</u>, *player*, *explicitDur*, *region*, *freeze*, *moveLeft*, *moveRight*, *moveUp*, *moveDown*, *focusIndex*, *focusBorderColor*, *focusBorderWidth*, *focusBorderTransparency*, *focusSrc*, *focusSelSrc*, *selBorderColor*, *transIn*, *transOut* | ([&lt;descriptorParam&gt;](descriptorparam.md))* | [&lt;descriptorBase&gt;](descriptorbase.md) |

### Atributos { data-search-exclude }

| Nombre | Valor | Descripción |
| --- | --- | --- |
| *id* | Puede recibir cualquier valor de cadena que comience con una letra o un guión bajo y que solo contenga letras, dígitos, "." y "_". | El atributo *id* identifica de forma única al elemento dentro de un documento. |
| *player* | Cadena. Si no se especifica, el reproductor está determinado por el tipo de objeto, definido por el atributo *type* del elemento [&lt;media&gt;](media.md), o se infiere por la extensión de archivo utilizada en el atributo *src* del elemento [&lt;media&gt;](media.md). | Identifica la herramienta de presentación que se utilizará. |
| *explicitDur* | <p>El atributo *explicitDur* se especifica de acuerdo con una de las siguientes sintaxis:</p><ol><li>"Hours:Minutes:Seconds.Fraction", donde "Hours" es un entero en el intervalo \[0,23\], "Minutes" es un entero en el intervalo \[0,59\], "Seconds" es un entero en el intervalo \[0,59\] y "Fraction" es un entero positivo,</li><li>Seconds"s", donde "Seconds" es un número real positivo.</li></ol><p>Para medios continuos, el valor predeterminado se establecerá en la duración natural; de lo contrario, debe establecerse en nulo (*nil*).</p> | Define la duración explícita de un objeto. |
| *region* | IDREF. | El atributo *region* identifica un elemento [&lt;region&gt;](region.md) utilizado para inicializar las propiedades *left*, *right*, *top*, *bottom*, *height*, *width* y *zIndex* del elemento [&lt;media&gt;](media.md) que hace referencia al elemento [&lt;descriptor&gt;](descriptor.md). |
| *freeze* | <p>"true" o "false".</p><p>El valor predeterminado es "false".</p> | El atributo *freeze* define qué sucederá con un objeto al final de su presentación, si el contenido final se congela ("true") o no ("false"). |
| *moveLeft* | Entero positivo. | El atributo *moveLeft* especifica un valor igual al valor *focusIndex* asociado a un elemento al que se debe aplicar el foco cuando se presiona la tecla de flecha izquierda. |
| *moveRight* | Entero positivo. | El atributo *moveRight* especifica un valor igual al valor *focusIndex* asociado a un elemento al que se debe aplicar el foco cuando se presiona la tecla de flecha derecha. |
| *moveUp* | Entero positivo. | El atributo *moveUp* especifica un valor igual al valor *focusIndex* asociado a un elemento al que se debe aplicar el foco cuando se presiona la tecla de flecha arriba. |
| *moveDown* | Entero positivo. | El atributo *moveDown* especifica un valor igual al valor *focusIndex* asociado a un elemento al que se debe aplicar el foco cuando se presiona la tecla de flecha abajo. |
| *focusIndex* | Entero positivo. | El atributo *focusIndex* especifica un índice para el elemento [&lt;media&gt;](media.md) al que se puede aplicar el foco. Cuando la propiedad correspondiente no está definida, el objeto se considera como si no pudiera recibir foco. |
| *focusBorderColor* | <p>"white", "black", "silver", "gray", "red", "maroon", "fuchsia", "purple", "lime", "green", "yellow", "olive", "blue", "navy", "aqua" o "teal".</p><p>El valor predeterminado viene dado por la propiedad "default.focusBorderColor" del objeto *settings*.</p> | Define el color para decorar la región de la pantalla donde se presenta el objeto en foco, antes de ser seleccionado. |
| *focusBorderWidth* | <p>Entero.</p><p>El valor predeterminado está definido por la propiedad "default.focusBorderWidth" del objeto *settings*.</p> | Ancho, en píxeles, aplicado al borde de un elemento en foco. |
| *focusBorderTransparency* | <p>Un número real en el intervalo \[0,1\], o un número real en el intervalo \[0,100\] que termina con el carácter "%" (por ejemplo, "30%").</p><p>El valor predeterminado está definido por la propiedad "default.focusTransparency" del objeto *settings*.</p> | Transparencia aplicada al borde de un elemento en foco, donde 1 o 100% significa transparencia total y 0 o 0% significa sin transparencia. |
| *focusSrc* | <p>Los siguientes son valores válidos:</p><ul><li><code>file:///file_path/#fragment_identifier</code> -- para archivos locales,</li><li><code>http://server_identifier/file_path/#fragment_identifier</code> -- para archivos remotos descargados mediante el protocolo HTTP,</li><li><code>https://server_identifier/file_path/#fragment_identifier</code> -- para archivos remotos descargados mediante el protocolo HTTPS,</li><li><code>rtsp://server_identifier/file_path/#fragment_identifier</code> -- para flujos descargados mediante el protocolo RTSP,</li><li><code>rtp://server_identifier/file_path/#fragment_identifier</code> -- para flujos descargados mediante el protocolo RTP,</li><li><code>ncl-mirror://media_element_identifier</code> -- para un flujo de contenido idéntico al que está en presentación por otro elemento [&lt;media&gt;](media.md),</li><li><code>sbtvd-ts:</code> o <code>isdb-ts:</code> o <code>ts://program_number.component_tag</code> -- para flujos elementales recibidos del flujo de transporte.</li></ul><p>Para el atributo *src* cuyo valor identifica el esquema "sbtvd-ts", "isdb-ts" o "ts", el "program_number.component_tag" puede sustituirse por las siguientes palabras reservadas:</p><ul><li>"video" -- correspondiente al ES de video primario presentado en el plano de video,</li><li>"audio" -- correspondiente al ES de audio primario,</li><li>"text" -- correspondiente al ES de texto primario,</li><li>"video(i)" -- correspondiente al *i*-ésimo menor "component_tag" de ES de video listado en la PMT de los servicios sintonizados,</li><li>"audio(i)" -- correspondiente al *i*-ésimo menor "component_tag" de ES de audio listado en la PMT de los servicios sintonizados, o</li><li>"text(i)" -- correspondiente al *i*-ésimo menor "component_tag" de ES de texto listado en la PMT de los servicios sintonizados.</li></ul> | El atributo *focusSrc* puede especificar una fuente multimedia alternativa para presentarse, en lugar de la presentación actual, si un elemento recibe el foco. Este atributo sigue las mismas reglas que el atributo *src* del elemento [&lt;media&gt;](media.md). |
| *focusSelSrc* | Igual que para *focusSrc*. | Cuando se selecciona un elemento en foco presionando la tecla de activación ("SELECT" o "ENTER"), la propiedad *focusSelSrc* puede especificar una fuente multimedia alternativa para presentarse en lugar de la presentación actual. Este atributo sigue las mismas reglas que el atributo *src* del elemento [&lt;media&gt;](media.md). |
| *selBorderColor* | <p>"white", "black", "silver", "gray", "red", "maroon", "fuchsia", "purple", "lime", "green", "yellow", "olive", "blue", "navy", "aqua" o "teal".</p><p>El valor predeterminado viene dado por la propiedad "default.selBorderColor" del objeto *settings*.</p> | Define el color para decorar la región de la pantalla donde se presenta el objeto en foco, después de ser seleccionado. |
| *transIn* | Lista de IDREFs separados por punto y coma. | El atributo *transIn* es una lista separada por punto y coma de identificadores de elementos [&lt;transition&gt;](transition.md). |
| *transOut* | Lista de IDREFs separados por punto y coma. | El atributo *transOut* es una lista separada por punto y coma de identificadores de elementos [&lt;transition&gt;](transition.md). |
