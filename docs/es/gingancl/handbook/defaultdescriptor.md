### Definición y uso { data-search-exclude }

El elemento [&lt;defaultDescriptor&gt;](../defaultdescriptor/) identifica al hijo predeterminado
[&lt;descriptor&gt;](../descriptor/) elemento del [&lt;descriptorSwitch&gt;](../descriptorswitch/) elemento que debe
se seleccionará si todas las reglas se evalúan como falsas.

### Sintaxis { data-search-exclude }

| Elemento | Atributos | Contenido | Padre |
| --- | --- | --- | --- |
| [&lt;defaultDescriptor&gt;](../defaultdescriptor/) | <u>*descriptor*</u> | -- | [&lt;descriptorSwitch&gt;](../descriptorswitch/) |

### Atributos { data-search-exclude }

| Nombre | Valor | Descripción |
| --- | --- | --- |
| *descriptor* | IDREF. | El atributo *descriptor* hace referencia a un elemento [&lt;descriptor&gt;](../descriptor/). |
