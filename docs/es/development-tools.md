# Herramientas de Desarrollo

<p class="guide-byline"><span>Por <b>Alan Guedes</b> (University of Reading)</span></p>

<div class="grid cards" markdown>

- :material-microsoft-visual-studio-code: **ginga-code**

    Extensión de VS Code para la ejecución de aplicaciones Ginga, basada en [gingaf](https://github.com/ginga-org-br/gingaf).

    [:octicons-arrow-right-24: Marketplace](https://marketplace.visualstudio.com/items?itemName=ginga-org-br.ginga-code)

- :material-play-circle: **ginga-playground**

    Entorno de ejecución en línea para experimentar con aplicaciones Ginga (NCL y HTML5), basado en [gingaf](https://github.com/ginga-org-br/gingaf).

    [:octicons-arrow-right-24: Probar](/gingaf/playground/)

</div>

## Otras Herramientas

<div class="grid cards" markdown>

- :material-web: **NCL Composer**

    Herramienta multiplataforma para la autoría y desarrollo de aplicaciones interactivas en NCL.

    [:octicons-arrow-right-24: Sitio de NCL Composer](http://composer.telemidia.puc-rio.br)

- :material-web: **NCL Eclipse**

    Plug-in para soporte a desarrollo NCL en el entorno Eclipse.

    [:octicons-arrow-right-24: Descarga / Información](http://www.telemidia.puc-rio.br/~roberto/ncleclipse)

- :material-github: **PUC-Rio Ginga**

    Implementación de referencia ITU-T del Reproductor Ginga, con interfaz gráfica para Windows.

    [:octicons-arrow-right-24: Repositorio GitHub](https://github.com/TeleMidia/ginga/)

</div>
