<div class="grid cards" markdown>

- :material-microsoft-visual-studio-code: **ginga-code**

    Extensão para o VS Code para execução de aplicações Ginga, baseada no [gingaf](https://github.com/ginga-org-br/gingaf).

    [:octicons-arrow-right-24: Marketplace](https://marketplace.visualstudio.com/items?itemName=ginga-org-br.ginga-code)

    Ambiente de execução online para experimentar com aplicações Ginga (NCL e HTML5), baseado no [gingaf](https://github.com/ginga-org-br/gingaf).

    [:octicons-arrow-right-24: Experimentar](/gingaf/playground/)

</div>
