### Definição e uso { data-search-exclude }

O elemento [&lt;defaultDescriptor&gt;](../defaultdescriptor/) identifica o filho padrão
Elemento [&lt;descriptor&gt;](../descriptor/) do elemento [&lt;descriptorSwitch&gt;](../descriptorswitch/) que deve
ser selecionado se todas as regras forem avaliadas como falsas.

### Sintaxe { data-search-exclude }

| Elemento | Atributos | Conteúdo | Pai |
| --- | --- | --- | --- |
| [&lt;defaultDescriptor&gt;](../defaultdescriptor/) | <u>*descritor*</u> | -- | [&lt;descriptorSwitch&gt;](../descriptorswitch/) |

### Atributos { data-search-exclude }

| Nome | Valor | Descrição |
| --- | --- | --- |
| *descritor* | IDREF. | O atributo *descriptor* refere-se a um elemento [&lt;descriptor&gt;](../descriptor/). |
