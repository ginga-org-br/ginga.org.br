# &lt;descriptor&gt;

O elemento [&lt;descriptor&gt;](descriptor.md) define os valores iniciais para propriedades de
[&lt;media&gt;](media.md) elementos.  Esses valores iniciais são definidos em atributos de
o elemento ou em elementos filhos [&lt;descriptorParam&gt;](descriptorparam.md).

### Sintaxe { data-search-exclude }

| Elemento | Atributos | Conteúdo | Pai |
| --- | --- | --- | --- |
| [&lt;descriptor&gt;](descriptor.md) | <u>*id*</u>, *player*, *explicitDur*, *region*, *freeze*, *moveLeft*, *moveRight*, *moveUp*, *moveDown*, *focusIndex*, *focusBorderColor*, *focusBorderWidth*, *focusBorderTransparency*, *focusSrc*, *focusSelSrc*, *selBorderColor*, *transIn*, *transOut* | ([&lt;descriptorParam&gt;](descriptorparam.md))* | [&lt;descriptorBase&gt;](descriptorbase.md) |

### Atributos { data-search-exclude }

| Nome | Valor | Descrição |
| --- | --- | --- |
| *id* | Pode receber qualquer valor de string que comece com uma letra ou um sublinhado e que contenha apenas letras, dígitos, "." e "_". | O atributo *id* identifica exclusivamente o elemento dentro de um documento. |
| *player* | String. Se não for especificado, o reprodutor é determinado pelo tipo de objeto, definido pelo atributo *type* do elemento [&lt;media&gt;](media.md), ou é inferido pela extensão do arquivo usada no atributo *src* do elemento [&lt;media&gt;](media.md). | Identifica a ferramenta de apresentação a ser usada. |
| *explicitDur* | <p>O atributo *explicitDur* é especificado de acordo com uma das seguintes sintaxes:</p><ol><li>"Hours:Minutes:Seconds.Fraction", onde "Hours" é um inteiro no intervalo \[0,23\], "Minutes" é um inteiro no intervalo \[0,59\], "Seconds" é um inteiro no intervalo \[0,59\] e "Fraction" é um inteiro positivo,</li><li>Seconds"s", onde "Seconds" é um número real positivo.</li></ol><p>Para mídia contínua, o valor padrão será definido para a duração natural; caso contrário, deverá ser definido como nulo (*nil*).</p> | Define a duração explícita de um objeto. |
| *region* | IDREF. | O atributo *region* identifica um elemento [&lt;region&gt;](region.md) usado para inicializar as propriedades *left*, *right*, *top*, *bottom*, *height*, *width* e *zIndex* do elemento [&lt;media&gt;](media.md) que faz referência ao elemento [&lt;descriptor&gt;](descriptor.md). |
| *freeze* | <p>"true" ou "false".</p><p>O valor padrão é "false".</p> | O atributo *freeze* define o que acontecerá com um objeto ao final de sua apresentação, se o conteúdo final será congelado ("true") ou não ("false"). |
| *moveLeft* | Inteiro positivo. | O atributo *moveLeft* especifica um valor igual ao valor *focusIndex* associado a um elemento ao qual o foco deve ser aplicado quando a tecla de seta para a esquerda for pressionada. |
| *moveRight* | Inteiro positivo. | O atributo *moveRight* especifica um valor igual ao valor *focusIndex* associado a um elemento ao qual o foco deve ser aplicado quando a tecla de seta para a direita for pressionada. |
| *moveUp* | Inteiro positivo. | O atributo *moveUp* especifica um valor igual ao valor *focusIndex* associado a um elemento ao qual o foco deve ser aplicado quando a tecla de seta para cima for pressionada. |
| *moveDown* | Inteiro positivo. | O atributo *moveDown* especifica um valor igual ao valor *focusIndex* associado a um elemento ao qual o foco deve ser aplicado quando a tecla de seta para baixo for pressionada. |
| *focusIndex* | Inteiro positivo. | O atributo *focusIndex* especifica um índice para o elemento [&lt;media&gt;](media.md) ao qual o foco pode ser aplicado. Quando a propriedade correspondente não está definida, o objeto é considerado como se nenhum foco pudesse ser aplicado. |
| *focusBorderColor* | <p>"white", "black", "silver", "gray", "red", "maroon", "fuchsia", "purple", "lime", "green", "yellow", "olive", "blue", "navy", "aqua" ou "teal".</p><p>O valor padrão é dado pela propriedade "default.focusBorderColor" do objeto *settings*.</p> | Define a cor para decorar a região da tela onde o objeto em foco está sendo apresentado, antes de ser selecionado. |
| *focusBorderWidth* | <p>Inteiro.</p><p>O valor padrão é definido pela propriedade "default.focusBorderWidth" do objeto *settings*.</p> | Largura, em pixels, aplicada à borda de um elemento em foco. |
| *focusBorderTransparency* | <p>Um número real no intervalo \[0,1\], ou um número real no intervalo \[0,100\] terminando com o caractere "%" (por exemplo, "30%").</p><p>O valor padrão é definido pela propriedade "default.focusTransparency" do objeto *settings*.</p> | Transparência aplicada à borda de um elemento em foco, com 1 ou 100% significando transparência total e 0 ou 0% significando nenhuma transparência. |
| *focusSrc* | <p>Os seguintes valores são válidos:</p><ul><li><code>file:///file_path/#fragment_identifier</code> -- para arquivos locais,</li><li><code>http://server_identifier/file_path/#fragment_identifier</code> -- para arquivos remotos baixados usando o protocolo HTTP,</li><li><code>https://server_identifier/file_path/#fragment_identifier</code> -- para arquivos remotos baixados usando o protocolo HTTPS,</li><li><code>rtsp://server_identifier/file_path/#fragment_identifier</code> -- para fluxos baixados usando o protocolo RTSP,</li><li><code>rtp://server_identifier/file_path/#fragment_identifier</code> -- para fluxos baixados usando o protocolo RTP,</li><li><code>ncl-mirror://media_element_identifier</code> -- para um fluxo de conteúdo idêntico ao que está em apresentação por outro elemento [&lt;media&gt;](media.md),</li><li><code>sbtvd-ts:</code> ou <code>isdb-ts:</code> ou <code>ts://program_number.component_tag</code> -- para fluxos elementares recebidos do fluxo de transporte.</li></ul><p>Para o atributo *src* cujo valor identifica o esquema "sbtvd-ts", "isdb-ts" ou "ts", o "program_number.component_tag" pode ser substituído pelas seguintes palavras reservadas:</p><ul><li>"video" -- correspondente ao ES de vídeo primário sendo apresentado no plano de vídeo,</li><li>"audio" -- correspondente ao ES de áudio primário,</li><li>"text" -- correspondente ao ES de texto primário,</li><li>"video(i)" -- correspondente ao *i*-ésimo menor "component_tag" de ES de vídeo listado na PMT dos serviços sintonizados,</li><li>"audio(i)" -- correspondente ao *i*-ésimo menor "component_tag" de ES de áudio listado na PMT dos serviços sintonizados, ou</li><li>"text(i)" -- correspondente ao *i*-ésimo menor "component_tag" de ES de texto listado na PMT dos serviços sintonizados.</li></ul> | O atributo *focusSrc* pode especificar uma fonte de mídia alternativa a ser apresentada, em vez da apresentação atual, se um elemento receber o foco. Este atributo segue as mesmas regras do atributo *src* do elemento [&lt;media&gt;](media.md). |
| *focusSelSrc* | Igual ao atributo *focusSrc*. | Quando um elemento em foco é selecionado ao pressionar a tecla de ativação ("SELECT" ou "ENTER"), a propriedade *focusSelSrc* pode especificar uma fonte de mídia alternativa a ser apresentada, em vez da apresentação atual. Este atributo segue as mesmas regras do atributo *src* do elemento [&lt;media&gt;](media.md). |
| *selBorderColor* | <p>"white", "black", "silver", "gray", "red", "maroon", "fuchsia", "purple", "lime", "green", "yellow", "olive", "blue", "navy", "aqua" ou "teal".</p><p>O valor padrão é dado pela propriedade "default.selBorderColor" do objeto *settings*.</p> | Define a cor para decorar a região da tela onde o objeto em foco está sendo apresentado, após ser selecionado. |
| *transIn* | Lista de IDREFs separados por ponto e vírgula. | O atributo *transIn* é uma lista separada por ponto e vírgula de identificadores de elementos [&lt;transition&gt;](transition.md). |
| *transOut* | Lista de IDREFs separados por ponto e vírgula. | O atributo *transOut* é uma lista separada por ponto e vírgula de identificadores de elementos [&lt;transition&gt;](transition.md). |
