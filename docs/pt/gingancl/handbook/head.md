### Definição e uso { data-search-exclude }

A tag [&lt;head&gt;](../head/) é o contêiner para todos os elementos principais.

Elementos filhos do elemento [&lt;head&gt;](../head/) promovem instalações de reutilização em NCL
documentos ou definir meta-informações para agentes de usuário de aplicativos NCL.

O elemento [&lt;head&gt;](../head/) não possui nenhum atributo.
