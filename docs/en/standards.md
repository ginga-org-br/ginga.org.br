# Standards

## SBTVD Standards

### TV 3.0 {#tv-30}

The [Brazilian Digital Terrestrial Television Forum](http://www.forumsbtvd.org.br) coordinated with ABNT the development of the TV 3.0 standards (commercially known as DTV+), available in the official [ABNT Catálogo](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) collection.

The normative set comprises ten documents published in 2025: the nine standards in the ABNT NBR 25601–25609 series and ABNT NBR 15606-11, which specifies the Ginga Common Core WebServices. NBR 25609 does not appear as a separate box in the layer diagram because it spans across all layers. For an interactive visual guide on how these layers operate together, see [TV 3.0 Architecture](guides/tv3.0-architecture.md).

| ABNT NBR | Topic | Scope | ABNT Catalog |
| :--- | :--- | :--- | :---: |
| **25601** | OTA physical layer | Complies with ATSC A/322. MIMO and LDM for spectral and energy efficiency, TxID for geographic segmentation. VHF or UHF from 44 MHz to 960 MHz, 6, 7, or 8 MHz channels | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **25602** | Transport layer | ROUTE/DASH from A/331. Adds BAMT and TBSAT to LLS, replaces HELD with BALD in SLS | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **25603** | Video coding | VVC, HEVC, AVC, and LCEVC; HDR10, SL-HDR1, SL-HDR2, HLG, and SMPTE ST 2094-10 and 2094-40; V3C for volumetric video | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **25604** | Audio coding | MPEG-H Audio as reference; AAC, AC-4, and E-AC-3 JOC also decoded | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **25605** | Captions | IMSC1 and WebVTT | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **25606** | Sign language | Libras video stream, gloss stream, and motion stream | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **25607** | Emergency alert | AEA system: AEA-MF messages carried in AEAT within LLS | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **25608** | Application coding | AoP, Ginga-NCL and Ginga-HTML5, WebServices, Application Catalog, Persistent Media Player, Access Panel, BALD, PRRD | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **25609** | Receivers | BDR, STB, and GTW; nine profiles from 4K@60fps to 8K@60fps; RF reception | [2025](https://www.abntcatalogo.com.br/pnm.aspx?Q=T3R6TlNsWGtvZkJKUlhNR2s4YjdyWEdSNU9JVllRM2RWaXBtZlpuNUlzYz0=#showH) |
| **15606-11** | TV 3.0 WebServices | Ginga Common Core WebServices — the API specification referenced by Annex C of 25608 | [2023](https://www.abntcolecao.com.br/coltv.aspx?Q=CING45WV08&ID=547257) |

The ABNT NBR 25601–25609:2025 set normatively builds upon:

- **ATSC**: A/321, A/322, A/324, A/330, A/331, A/332, and A/360
- **ISO/IEC**: 23009-1 (MPEG-DASH)
- **IETF**: RFC 8216 (HLS) and RFC 1952 (GZIP)
- **ITU-T**: X.1303 bis (Common Alerting Protocol — CAP)
