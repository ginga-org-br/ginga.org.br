### Definition and Usage { data-search-exclude }

The [&lt;descriptorBase&gt;](../descriptorbase/) element groups a set of [&lt;descriptor&gt;](../descriptor/)
elements, each of which defines initial values of [&lt;media&gt;](../media/) properties.

### Syntax { data-search-exclude }

| Element | Attributes | Content | Parent |  |  |
| --- | --- | --- | --- | --- | --- |
| [&lt;descriptorBase&gt;](../descriptorbase/) | *id* | ([&lt;importBase&gt;](../importbase/) | [&lt;descriptor&gt;](../descriptor/) | [&lt;descriptorSwitch&gt;](../descriptorswitch/))+ | [&lt;head&gt;](../head/) |

### Attributes { data-search-exclude }

| Name | Value | Description |
| --- | --- | --- |
| *id* | It may receive any string value that begins with a letter or an underscore and that only contains letters, digits, <".">, and <"_">. | The *id* attribute uniquely identifies the element within a document. |
