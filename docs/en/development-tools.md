# Development Tools

Tools for developing and running Ginga applications in NCL and HTML5.

<div class="grid cards" markdown>

- :material-microsoft-visual-studio-code: **ginga-code**

    VS Code extension for the execution of Ginga applications, powered by [gingaf](https://github.com/ginga-org-br/gingaf).

    [:octicons-arrow-right-24: Marketplace](https://marketplace.visualstudio.com/items?itemName=ginga-org-br.ginga-code)

- :material-play-circle: **ginga-playground**

    Online execution environment to experiment with Ginga applications (NCL and HTML5), powered by [gingaf](https://github.com/ginga-org-br/gingaf).

    [:octicons-arrow-right-24: Try it](/gingaf/playground/)

</div>
